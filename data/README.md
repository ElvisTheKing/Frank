# Local RAW corpus

Place private test photographs in this directory. Everything except this README is ignored by Git.

The current local acceptance corpus contains eight Olympus/OM System OM-5 ORF files: six high-resolution files with an approximately 80.6 MP crop and two files with an approximately 49.9 MP crop. Tests and benchmarks must open these files read-only and must write all generated previews, pyramids, reports, or converted images under the ignored dist or .imagecompare-cache directories.
